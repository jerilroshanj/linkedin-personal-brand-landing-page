# LinkedIn Personal Brand Landing Page

A modern, responsive landing page concept for a LinkedIn personal branding service.

The page is designed around converting visitors into leads through a clear value proposition, social proof, an audit offer, and a lead capture form.

## 🚀 Live Demo

https://website-antany.vercel.app/

## ✨ Features

- Responsive landing page
- Modern UI/UX
- Hero section
- Achievement/results section
- Lead capture form
- ₹1 audit CTA
- Testimonials/reviews section
- FAQ section
- Responsive navigation
- Payment CTA integration
- Google Sheets lead collection
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- Cashfree
- Vercel

## 🎯 Purpose

This project was created as a personal practice and portfolio project to explore:

- Landing page design
- Responsive web development
- Conversion-focused UI
- Form handling
- Third-party integrations
- Deployment using Vercel
